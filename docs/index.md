# Weblate Provider

Manages the configuration of a Weblate instance through its REST API.

## Requirements

- OpenTofu 1.11 or later, or Terraform 1.11 or later.
- Weblate `2026.10.1` or later.

## Authentication

The provider authenticates with an API token. A User token (`wlu_…`) can manage every object its user has the
permissions for; instance-wide objects such as Groups need a user with administration rights. A Project token
(`wlp_…`) can manage only objects inside its Project.

## Example Usage

```terraform
provider "weblate" {
  url = "https://weblate.example.com"
  # Leave out token and set the WEBLATE_API_TOKEN environment variable, so the token stays out of the configuration.
}
```

## Schema

### Optional

- `token` (String, Sensitive) API token of a Weblate user (`wlu_…`) or Project (`wlp_…`). Defaults to the `WEBLATE_API_TOKEN` environment variable.
- `url` (String) Base URL of the Weblate instance, such as `https://weblate.example.com`, or `https://example.com/weblate` for an instance served under `WEBLATE_URL_PREFIX`. The provider appends `/api/` itself, so the URL must not end in `/api`. Defaults to the `WEBLATE_URL` environment variable.
